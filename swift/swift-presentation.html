INTRODUÇÃO AO SWIFT

Swift é uma linguagem moderna, rápida e segura para criar aplicativos em todas as plataformas Apple e além.

DEFINIÇÃO

O QUE É SWIFT?

O Swift é uma linguagem de programação moderna, rápida e segura criada pela Apple.

Use-o para criar aplicativos para iPhone, iPad, Mac, Apple Watch e Apple TV.

Você também pode executar o Swift em servidores (Linux, Windows, macOS).

O Swift ajuda a escrever códigos corretos e eficientes com inferência de tipos, optionals, tipos de valor e programação orientada a protocolos.

Destaques

  • ⚡ Criado pela Apple
  • ⚡ iOS, iPad, Mac, Watch, TV
  • ⚡ Compatível com Servidor
  • ⚡ Recursos Seguros e Eficientes

VANTAGENS

POR QUE USAR O SWIFT?

O Swift tem foco em segurança e velocidade.

Recursos como optionals, tipos de valor e genéricos ajudam a evitar bugs e a manter o código limpo.

  • ✓ Excelente para o desenvolvimento no iPhone/iPad, Mac, Apple Watch e Apple TV
  • ✓ Código aberto e disponível em múltiplas plataformas
  • ✓ Sintaxe expressiva, opcionais para modelar ausência de valores e tipos de valor para comportamento previsível
  • ✓ Ecossistema vibrante e ferramentas de primeira classe no Xcode

Destaques

  • ⚡ Foco em Segurança e Velocidade
  • ⚡ Optionals, Valores, Genéricos
  • ⚡ Código Aberto
  • ⚡ Ferramentas e Ecossistema Xcode
LINHA DO TEMPO

HISTÓRIA DO SWIFT

Uma breve linha do tempo com os principais lançamentos e marcos do Swift.

2014

Swift 1.0 anunciado na WWDC como um sucessor moderno do Objective-C

2015

O Swift tornou-se código aberto em swift.org, com suporte para Linux

2019

O Swift 5 introduziu estabilidade de ABI nas plataformas Apple

2021

O Swift 5.5 adicionou concorrência estruturada (async/await, Task, actor)

HOJE

Usado amplamente em iOS, macOS e no lado do servidor

REQUISITOS

MAC E XCODE PARA DESENVOLVIMENTO IOS

Se o seu objetivo é criar e rodar aplicativos iOS, você deve usar um Mac com o Xcode.

  • ▪ O Xcode includes as SDKs do iOS, simuladores, o Interface Builder e ferramentas de assinatura de código.
  • ▪ Você pode aprender Swift no Windows, Linux ou no próprio navegador, mas criar e rodar aplicativos iOS exige um Mac.
  • ▪ Para publicar no TestFlight ou na App Store, você precisará de uma conta de desenvolvedor da Apple.
Quando estiver pronto para criar aplicativos iOS, instale o Xcode diretamente da Mac App Store.

Destaques

  • ⚡ Mac + Xcode é essencial para iOS
  • ⚡ Xcode traz SDKs e Simuladores
  • ⚡ Conta de Desenvolvedor para envio
