SWIFT: COMO COMEÇAR

Instale a toolchain oficial do Swift, configure o seu ambiente de desenvolvimento e execute seu primeiro programa "Hello, Swift!" no terminal ou utilizando o Xcode no macOS.

INSTALAÇÃO

COMO INSTALAR O SWIFT

O Swift pode ser instalado em múltiplos sistemas operacionais (macOS, Windows e Linux).

▪
macOS (Xcode) Instale o Xcode diretamente da App Store. Ele inclui automaticamente o compilador Swift, simuladores iOS e todas as ferramentas oficiais.
▪
macOS (Linha de Comando) Se preferir não baixar a IDE completa, você pode instalar apenas a toolchain da linha de comando oficial no site oficial.
▪
Windows e Linux Baixe a plataforma toolchain oficial diretamente de swift.org/install e certifique-se de configurar o executável no seu PATH global.

Guia Rápido

  • ⚡ macOS: Xcode na App Store
  • ⚡ Win/Linux: swift.org/install
  • ⚡ Multiplataforma
  • ⚡ Gratuito e Código Aberto
VERIFICAÇÃO

VERIFICANDO A INSTALAÇÃO

Para garantir que o Swift foi instalado com sucesso e está devidamente configurado nas suas variáveis de ambiente, você pode consultar o compilador diretamente pelo terminal.

Abra o seu terminal (macOS/Linux) ou Prompt de Comando (Windows) e execute o comando abaixo. Ele deve imprimir a versão ativa do Swift e o target do sistema operacional.

Terminal 
$ swift --version
swift-driver version: 1.90.11.1 Apple Swift version 5.10
Target: arm64-apple-darwin23.4.0

Dicas

  • ⚡ Digite `swift --version`
  • ⚡ Verifica se está no PATH
  • ⚡ Mostra versão ativa
  • ⚡ Exibe arquitetura do target
CÓDIGO

PRIMEIRO PROGRAMA: HELLO WORLD

Em Swift, o clássico "Hello World" é incrivelmente direto. Você não precisa importar bibliotecas complexas para entrada/saída ou encapsular o ponto de entrada em uma classe ou função.

main.swift 
print("Hello, Swift!")

Dica: Experimente testar e rodar o Swift online sem instalar nada em seu computador local.

EXECUÇÃO

EXECUTANDO NO TERMINAL

Para criar e rodar o seu script Swift passo a passo utilizando comandos do terminal:

  1. Crie um diretório de testes: mkdir hello-swift
  2. Entre no diretório: cd hello-swift
  3. Crie o arquivo com o comando print direcionado ao arquivo main.swift
  4. Execute o script usando a toolchain: swift main.swift
Terminal 
$ mkdir hello-swift
$ cd hello-swift
$ printf "print(\"Hello, Swift!\")\n" > main.swift
$ swift main.swift
Hello, Swift!

Resumo Terminal

  • ⚡ `mkdir` e `cd`
  • ⚡ Criar arquivo `.swift`
  • ⚡ Comando `swift [arquivo]`
  • ⚡ Compila e roda na hora
DETALHES

ENTENDENDO O CÓDIGO EXPLICADO

Por que esse código tão simples funciona sem o boilerplate clássico de linguagens como Java ou C#?

main.swift Todo código escrito no nível superior (top-level execution) de um arquivo chamado main.swift é considerado o ponto de entrada oficial do programa e roda sequencialmente de cima para baixo.

função print() É uma função global integrada da biblioteca padrão do Swift que escreve valores de texto diretamente na saída padrão (standard output/console), adicionando uma quebra de linha no final de forma automática.

Aspas Duplas ("...") As strings literais em Swift devem sempre ser envoltas por aspas duplas. O uso de aspas simples (') gera erros de sintaxe.

Regras Chave

  • ⚡ Ponto de entrada no main.swift
  • ⚡ print() é global
  • ⚡ Quebra de linha automática
  • ⚡ Strings com aspas duplas
AMBIENTE APPLE

SWIFT DENTRO DO XCODE

Para o desenvolvimento profissional de aplicativos iOS, iPadOS ou macOS, a IDE Xcode é indispensável.

Novo Projeto de App Abra o Xcode, clique em "Create New Xcode Project", escolha a categoria "iOS" e selecione o modelo "App". Certifique-se de escolher **Swift** como a linguagem padrão.

Simulador iOS Integrado O Xcode vem com simuladores integrados de iPhones e iPads para compilar, executar e testar o layout de seus aplicativos em tempo real.

Playgrounds Para testar sintaxes simples, criar algoritmos rápidos ou experimentar recursos gráficos sem a complexidade de criar um projeto completo, use os **Xcode Playgrounds**.

Xcode Tools

  • ⚡ Xcode App Templates
  • ⚡ iOS/iPadOS/macOS SDKs
  • ⚡ Simuladores Locais
  • ⚡ Xcode Playgrounds interativos
