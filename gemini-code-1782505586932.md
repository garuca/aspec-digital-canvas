# 🚀 Checklist de Otimização SEO: ASPEC Soluções em Tecnologia

Este documento apresenta o diagnóstico e o roteiro de implementação para levar o site da **ASPEC** ao topo das buscas orgânicas, focando em palavras-chave de alta conversão em desenvolvimento de software e Inteligência Artificial.

---

## 🛠️ 1. Meta Tags e Otimizações de Cabeçalho (Head)

### 🔹 Ajuste no Meta Title
* **Como está:** `<title>ASPEC | Desenvolvimento de Software, Aplicativos e Inteligência Artificial</title>`
* **Problema:** Está bom, mas pode ser otimizado para o algoritmo do Google priorizar o core business e a localidade de atuação principal.
* **Alteração:** Substitua por:
    ```html
    <title>ASPEC | Desenvolvimento de Software & Inteligência Artificial em Goiânia</title>
    ```

### 🔹 Ajuste na Meta Description
* **Como está:** `content="Empresa especializada em desenvolvimento de software sob medida, aplicativos Android e iOS, sistemas web, automação empresarial e soluções com Inteligência Artificial."` (168 caracteres)
* **Problema:** Passa ligeiramente do limite ideal recomendado (150-160 caracteres), correndo o risco de ser cortada com reticências `...` nos resultados de busca mobile.
* **Alteração:** Reduza e adicione um gatilho de CTA:
    ```html
    <meta name="description" content="Empresa de desenvolvimento de software sob medida em Goiânia. Especialistas em sistemas web, aplicativos mobile e Inteligência Artificial. Solicite um orçamento!" />
    ```

## 📐 2. Correção Crítica da Hierarquia de Tags (Heading Tags)

O maior problema de SEO On-Page atual do código está na distribuição de tags `<h1>`, `<h2>` e `<h3>`. O robô do Google lê a página de forma linear e espera uma estrutura lógica perfeita.

### 🛑 O erro atual encontrado:
* A tag `<h1>` está ótima no Hero.
* Abaixo dela, a seção "SOBRE NÓS" usa um `<h2>`.
* Porém, a seção anterior ("NOSSO DIFERENCIAL") e as seções posteriores ("NOSSOS PROJETOS", "STACK DE DESENVOLVIMENTO", "IMPACTO EM NÚMEROS") também usam `<h2>`.
* Dentro de "NOSSOS PROJETOS", os nomes das empresas (Banco BV, Itaú) estão como `<h3>`. Até aqui, tudo bem.
* **O erro:** Na seção "SERVIÇOS" (O QUE FAZEMOS), o título principal está como `<h2>`, mas os subtítulos internos (Sites & Sistemas Web, Apps Mobile) foram marcados como `<h4>` pulando a tag `<h3>`, quebrando a hierarquia estrutural.

### ✅ Correção semântica a ser aplicada:

Substitua a estrutura atual das seções pelas seguintes diretrizes:

1.  **Seção Hero (Início):** Manter o `<h1>` atual.
2.  **Seção Sobre Nós:** Manter o `<h2>` atual (*EMPRESA DE DESENVOLVIMENTO DE SOFTWARE EM GOIÂNIA*).
3.  **Seção Diferenciais:** Manter `<h2>` para o título principal. Mudar os títulos dos 3 cards (*Time Completo*, *Foco em Resultado*, *Velocidade*) de `<h3>` para `<p class="font-mono text-lg font-bold">`, pois eles não são subtemas amplos de conteúdo.
4.  **Seção Metodologia:** Manter `<h2>`. Mudar os pilares de `<h3>` para `<p>`. Mudar os passos (01, 02, 03, 04) para `<h3>` (Ex: `<h3>Entendemos Seu Problema Antes de Criar Qualquer Solução</h3>`).
5.  **Seção Portfólio (Projetos):** Manter `<h2>`. Manter as tags `<article>` com seus respectivos `<h3>` para cada projeto (Banco BV, Itaú, etc.).
6.  **Seção Serviços:** Manter `<h2>` (*DESENVOLVIMENTO WEB, APPS E IA*). Mudar o título do bloco (*Tecnologia & Dev*) para `<h3>`. **Mudar os 6 itens internos (Sites, Apps, APIs, Automação, Consultoria, IA) de `<h4>` para `<h4>` apenas se estiverem abaixo de um H3 válido, ou manter como `<h4>` organizando a árvore de nós corretamente.** Como "Tecnologia & Dev" passará a ser `<h3>`, os itens internos obrigatoriamente devem ser `<h4>` (Correto!).
7.  **Seção FAQ:** Mudar as perguntas que estão dentro do botão de `<span class="font-mono text-sm font-bold">` para `<h3>` ou `<h4>`. Isso fará com que o Google indexe as perguntas frequentes diretamente nas buscas textuais como respostas rápidas.

## ♿ 3. Acessibilidade e SEO de Imagens (Atributos `alt`)

O Google pune páginas que usam atributos `alt` de imagens apenas para descrever palavras-chave artificiais (Keyword Stuffing).

### 🔹 Correção nas Imagens dos Clientes (Marquee)
* **Como está:** `alt="Assistente Virtual com IA desenvolvido pela ASPEC para o Banco Itaú"`
* **Problema:** A imagem em si é apenas o logotipo do banco (vetor), e não o assistente. O robô do Google e os leitores de tela para deficientes visuais sabem identificar essa discrepância.
* **Alteração:** Mude os textos alternativos para serem puramente descritivos do elemento gráfico:
    ```html
    alt="Logotipo oficial em tons de cinza do Banco Itaú, cliente parceiro da ASPEC"
    ```
    *(Faça o mesmo para Kovi, BV, SL Mandic, etc., mantendo a descrição exata do logotipo).*

## 🔗 4. Link Building Interno e Semântica HTML

### 🔹 Links de "Saiba Mais" na Metodologia
* **Como está:** `<button ... onclick="openArticleModal('01')">SAIBA MAIS</button>`
* **Problema:** Botões que abrem modais via JavaScript puro escondem texto que poderia estar renderizado nativamente para o robô de indexação (Googlebot). Além disso, o texto "SAIBA MAIS" é semanticamente fraco para o SEO.
* **Alteração:** Adicione um atributo `aria-label` descritivo nos botões de trigger dos artigos:
    ```html
    <button aria-label="Saiba mais sobre o diagnóstico preciso de software da ASPEC" onclick="openArticleModal('01')">...
    ```

### 🔹 Tags de Ênfase no Bloco de Texto "Sobre Nós"
* **Problema:** O uso excessivo de tags `<strong>` seguidas confunde o peso semântico do parágrafo para os algoritmos de NLP (Processamento de Linguagem Natural) do Google.
* **Como está:** `A <strong>ASPEC</strong> é uma <strong>empresa de desenvolvimento de software</strong> sediada em <strong>Goiânia</strong>...`
* **Alteração:** Deixe em negrito apenas a palavra-chave principal por parágrafo para focar a autoridade semântica:
    ```html
    A ASPEC é uma <strong>empresa de desenvolvimento de software em Goiânia</strong> que atende negócios em todo o Brasil...
    ```

## ⚡ 5. Otimizações de Performance com Impacto no Core Web Vitals

Como você utiliza a CDN do Tailwind e scripts de terceiros via tags `<script>`, a velocidade de carregamento (LCP e TBT) precisa de atenção para não perder nota no PageSpeed Insights.

1.  **Imagens do Portfólio (Modais):** Certifique-se de que as imagens listadas no banco de dados javascript (`portfolio/slmandic/unnamed.webp`, etc.) possuam dimensões explícitas em seus respectivos mockups para evitar *Cumulative Layout Shift (CLS)* quando abertas em lightbox.
2.  **Scripts de Terceiros (Clarity e Analytics):** Adicione o atributo `defer` ou mova a inicialização do Microsoft Clarity e do GA4 para o final da tag `<body>` para garantir que o HTML e o CSS principal (LCP) renderizem sem bloqueio de renderização (*render-blocking scripts*).
